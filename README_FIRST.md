# Bio Pulse — Complete GitHub Site

This folder is intended to replace the contents of the existing Bio-Pulse GitHub repository.

## IMPORTANT
Do **not** upload the ZIP file itself into the repository. Extract it first.

### Your current GitHub folder
The existing project you showed in your screenshot can be cleared and replaced with this project's contents.

### After copying these files
Open GitHub Desktop:
1. Confirm repository: `Bio-Pulse`
2. Check the changed files.
3. Commit the changes.
4. Push origin.

### Build
The project is a Vite + React site.

```bash
npm install
npm run build
```

Netlify settings already used by the existing project are compatible:
- Build command: `npm run build`
- Publish directory: `dist`
